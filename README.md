Unit Converter
A beginner-friendly unit converter built using Python.

Features
This program supports four conversions:

1. Meter to Centimeter
2. Meter to Millimeter
3. Centimeter to Meter
4. Millimeter to Centimeter

Technologies Used
- Python
- Conditional statements (`if`, `elif`, `else`)
- User input (`input()`)
- Basic mathematical operations

How to Run
1. Install Python.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

```
python unit_convertor.py
```

Learning Purpose
This is one of my beginner Python projects, created to practise conditional statements, user input, and mathematical operations.
